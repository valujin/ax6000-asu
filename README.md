# AX6000 Attended Sysupgrade

Специализированный форк [OpenWrt ASU](https://github.com/openwrt/asu/tree/77c5636045b0aed0762727363be105b2a5fa47fd) для Xiaomi Redmi AX6000 с vendor-драйверами MediaTek. Публичный адрес проекта: `https://asu.ezon.by`.

| Канал | База | Формат пакетов | API |
| --- | --- | --- | --- |
| 6.6 | ImmortalWrt 24.10, PadavanOnly | OPKG/IPK | `/66/` |
| 6.12 recommended | ImmortalWrt 25.12, vendor | APK v3 | `/612/recommended/` |
| 6.12 latest | ImmortalWrt 25.12, vendor | APK v3 | `/612/latest/` |

Сервер принимает только поколения, прошедшие проверку прошивки, соответствующего ImageBuilder и подписанного снимка пакетов. Он сохраняет разметку, проверяет полный ABI ядра и фактический состав образа. Tailscale включается в индивидуальный образ только по запросу устройства, на котором он уже установлен; обычные прошивки остаются без него. Переход OPKG → APK выполняется новой прошивкой, а не заменой менеджера пакетов на работающей системе.

Один worker использует отдельный rootless Docker. Сборочный контейнер сам держит общий lock до завершения, включая случай аварии worker. Ограничения: CPU 0–3, четыре CPU по квоте, 10 ГиБ RAM без swap, 2048 процессов. API и Redis не имеют Docker socket; worker имеет доступ только к отдельному сборочному движку.

APK-репозитории публичных userspace-пакетов проверяются официальными ключами, фиксируются и доступны через ограниченное зеркало. Они не заменяют наше ядро, vendor-стек и защищённые системные пакеты. Несовместимая зависимость приводит к отказу сборки.
